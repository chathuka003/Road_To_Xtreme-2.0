IEEE Road to Xtreme 🚀

A modern and responsive website developed for the IEEE Road to Xtreme initiative. The website provides information about the program, its activities, roadmap, and opportunities for participants.

🛠️ Tech Stack

- Next.js – React framework for building the web application
- TypeScript – Type-safe and maintainable development
- Tailwind CSS – Responsive and modern UI styling

✨ Key Features

- Modern and responsive user interface
- Informative About section
- Structured Roadmap section
- Mobile-friendly design
- Clean and reusable UI components
- Smooth and engaging user experience
